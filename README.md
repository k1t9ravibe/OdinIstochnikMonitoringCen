# Один источник — мониторинг цен

Сайт для мониторинга цены из одного источника — публичного API Binance (ключ не нужен).

- текущая цена, изменение за 24ч, максимум и минимум
- график истории, история хранится в браузере (localStorage)
- оповещения: выше/ниже порога и резкое изменение в % за один опрос
- уведомления браузера, выгрузка истории в CSV

## Запуск

Откройте `index.html` в браузере. Либо включите GitHub Pages (Settings → Pages → Deploy from branch → `main` / root),
и сайт будет доступен по адресу `https://k1t9ravibe.github.io/OdinIstochnikMonitoringCen/`.

Мониторинг идёт, пока вкладка открыта.
